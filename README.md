# 90일 리듬 트래커

수면, 음주, 작업 블록, 끌림을 90일 동안 기록하는 단일 파일 웹앱입니다.
서버 없이 브라우저에서만 동작하고, 기록은 각자의 기기에 저장됩니다.

## 기능
- 오늘 기록: 기상·취침·밤 폰 종료, 술, 작업 블록, 에너지, 한 줄
- 주간 점검: 작업 블록·술자리·늦은 취침·완성물 자동 집계, 회고 메모
- 부러움 분해: 과정/결과 분리와 비밀 검사
- 완성물 로그, 도피/학습 판별
- 30·60·90일 점검표 (기록에서 자동 계산)
- 백업 복사와 붙여넣기 복원

## 사용
`index.html`을 브라우저로 열면 됩니다. 처음 열 때 시작일을 고릅니다.
기기를 바꿀 때는 점검 탭의 "기록 백업 복사"로 복사해 새 기기에서 "복원"하세요.
브라우저 데이터를 지우면 기록도 지워지니 가끔 백업하세요.

## 배포 (GitHub Pages)
1. 공개 저장소를 만들고 `index.html`, `sw.js`, `README.md`, `LICENSE`를 올립니다.
2. Settings → Pages → Source를 "Deploy from a branch", 브랜치 `main`, 폴더 `/ (root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/`로 열립니다.
4. 휴대폰에서 열고 "홈 화면에 추가"한 뒤 한 번 열어 두면 오프라인에서도 열립니다.
